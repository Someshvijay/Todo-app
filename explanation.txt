The test file server/__tests__/todos.test.js contains five incorrect assertions expecting HTTP status 999 instead of 200 for happy-path requests (GET /api/todos, GET /api/todos/:id, PUT /api/todos/:id, PATCH /api/todos/:id/complete, DELETE /api/todos/:id). The application code in app.js is correct and actually returns 200 in these cases; only the test expectations were wrong, likely due to a botched merge or placeholder values. The fix replaces all five toBe(999) calls with toBe(200).
